# Contributing

Follow this checklist whenever adding or updating a component in `@moa-eth/moa-design-library`:

1. **Implement the component** under `src/components/<Name>/` (`<Name>.tsx`, `types.ts`, `styles.ts` if needed, `index.ts`, `<Name>.test.tsx`) and export it from `src/index.ts` and `docs-nextra/registry/moa-entry.ts`.
2. **Add an AI contract** in `ai/contracts/components/<Name>.json` and register `<Name>` in `ai/contracts/index.json`.
3. **Add a live preview** under `docs-nextra/registry/components/<slug>/<Name>Example.tsx`, register it in `docs-nextra/registry/components/index.ts`, add docs metadata in `docs-nextra/components/ComponentDocsPage.tsx`, and create `pages/components/<slug>.mdx`.
4. **Verify all checks**:

```bash
pnpm validate:contracts
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm docs:build
```

5. **Add a Changeset** (`pnpm changeset`) and use Conventional Commits (`feat: ...`, `fix: ...`).
